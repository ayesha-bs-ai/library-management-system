# Library Management System

A repository for a Java-based web application that will manage a library's books, members, borrowing, and returns.

## Status

Initial repository scaffold. Application development has not started yet.

## Planned Features

- Book catalog management
- Member registration and management
- Book issue, return, and renewal workflows
- Availability and overdue tracking
- Search and reporting

## Intended Platform

- Java web application
